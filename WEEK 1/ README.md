# pfa-week01
Labyrinth Gui

This tool procedurally generates a single-path circular labyrinth in Maya's python script editor tab. It contains ring walls with one continuous and winding route from an outer entrance to the center of the labyrinth with no dead ends.

This script is meant to be run in the python tab of the Maya script editor. When executed you can then use the “Circular Labyrinth Generator” window’s
sliders to set different parameters within the labyrinth; ring count, radius, wall size, etc, and then click generate. 

In the future I would add a color wheel option to the Gui and as well a variety in the shpaes the labyrinth could take on; a square, triangle, rectangle, and potentially even walls that swerve in diferent ways.
